# 真人测试登记（manual-test）

> GUIDE §0.16 真人测试闸门的登记处。**本表计数与 bug-ledger 严格分开**：AI 收敛计数 = 「修没修对」；本表真人验收计数 = 「东西对不对/能不能用」。
> 阈值：同一问题真人反馈 1 次=正常修；2 次=必须换思路；3 次=上升到需求层重做或砍，不做第 4 次同向微调。

## MT-001 · 主动气泡改版（N1+N2+N3）

- **登记日期**：2026-09-20 ｜ **状态**：待测
- **目标**（用户视角）：作为看简历的 HR，浏览这份简历时不应被反复打扰；被提示时能一眼知道这提示是怎么回事、并能一键让它别再出现。
- **前置条件**：`node dev.mjs`（或任意能打开站点的环境），浏览器访问首页；手机/窄屏（<600px）也算一轮。
- **步骤**：
  1. 打开首页，什么都不点，放着看约 2 分钟。
  2. 期间正常往下滚动浏览各个板块，在每个板块停留十几秒。
  3. 按你的习惯把整个简历完整过一遍，想聊天就聊天、想留联就留联。
  4. 用完后（或在聊天过程中）把「不再被主动提示」这个能力关掉。
- **成功判据**：全程自动出现的提示气泡不超过 2 次；第一次出现时能看到一行小字说明；关掉后无论停留多久都不再出现；页面布局无任何元素溢出/错位/遮挡。
- **体感记录项**（只有真人能答，必填）：
  - 第 1、2 次气泡出现的那一刻，你是「正好需要」还是「被打扰」？在哪个板块？
  - 说明行那行小字，你注意到了吗？读完相信吗（会不会反而意识到「原来它在跟着我看」）？
  - 「别主动找我」这个开关，你**自己找到了吗**？从产生念头到勾上花了几秒？
  - 7 条话术（N5 前仍是 AI 腔版本）里最别扭的一条是哪条？
- **耗时预估**：8–12 分钟（正常浏览简历的时长，不用额外腾时间）
- **真人验收计数**：0（首次登记）
- **不通过时怎么报**：按「现象 + 在哪个板块 + 当时第几次弹」一句话即可，例：「skills 区第 2 弹太快，像定时器不是像我停下来看的」。**不用**给修复方案，方向由下一轮判定（2 次换思路、3 次上抬需求层）。

## MT-002 · 留资闸门上线前的真人放行确认（N9）

- **登记日期**：2026-09-20 ｜ **状态**：待测
- **目标**（用户视角）：作为看完简历想留联系方式的 HR，我在页面里留联系方式这件事必须能成功、且我填的内容被原样记下；同时不该有人在我看不见的地方替我提交。
- **前置条件**：`node dev.mjs`（默认 127.0.0.1:8788），**用真实浏览器**（Chrome/Safari 各一次，含手机访问一次）打开首页。
- **步骤**：
  1. 浏览到你想联系的板块，把联系方式留下并提交。
  2. 提交完，打开看板页核对刚那条在不在、字段对不对。
  3. 再试一次：在**另一个网站**的开发者工具里，或用无痕窗口之外的方式，设法以「外部页面」的身份提交一次（想不到怎么做就跳过，跳过请在体感项写「没想到入口」）。
  4. 手机用流量（非同一 WiFi）访问一次并留资。
- **成功判据**：第 1 步必显示成功提示且看板能读到该条、字段无丢失；第 3 步若真做了一次外部提交，必须被拒绝（403）而不是落库；任何一次正常提交都**不得**出现「提交失败，稍后再试」。（注：`file://` 双击打开时留资本来就不可用，属设计内，不计失败。）
- **体感记录项**（必填）：
  - 提交后到看到「已收到」之间的等待，你觉得长了吗？大概几秒？
  - 你有没有一瞬间意识到「我填的东西被存到哪了」？这一刻是安心还是不安？
  - 第 3 步你自己想到了入口吗？（这条决定「同源校验」在真实世界到底挡不挡得住人）
  - 手机端与桌面端在这一步的体验有差别吗？
- **耗时预估**：5 分钟
- **真人验收计数**：0（首次登记）
- **不通过时怎么报**：报「哪一步 + 看到了什么提示 + 浏览器与网络环境」，例：「手机上第 1 步显示提交失败，Safari 流量访问」。特别地：**若出现正常访客被 403 挡掉，属最高优先级，立即回报并附 Origin 值**（这是本轮改动唯一可能伤到真实用户的地方）。
