# INSIGHTS：这个项目里值得看的思路

> 本文写给翻进 `docs/` 的读者（HR / 工程师）：不罗列功能，只讲**决策**。
> 每条思路都能溯源到具体文件与提交——判断力要经得起 `git log` 对质。

## 〇、一句话

这是一个把「简历」重构成 **Agent** 的项目：它不是一份挂在网上等看的 PDF，而是一个替本人向 HR 打招呼的分身——访客看简历时它在场、能答、知道自己什么时候该闭嘴。

## 一、先定第一性，再写代码：体验指标验收，不用功能指标

项目开工前先钉死一条验收标准：**目标用户是 HR，不一定懂技术，但一定有感受**。
所以验收指标不是"用了什么架构"，而是：

| 维度 | 指标 |
|---|---|
| 快 | 首字响应尽量 < 1.2s；工具执行期间界面必须显示"正在查…"，不让访客对着空白等 |
| 像人 | 答不了就说不确定，并主动说"我让他本人回你"——比编造强得多 |
| 不折腾 | 想联系时不必翻页面找入口，一次对话解决 |
| 不烦人 | 主动开口有硬上限；访客没表现意向时不追着要联系方式 |

技术选型全部从这张表倒推：比如"简历内容按需加载而不是每轮整份塞给模型"（`shared/prompt.mjs`），理由只有一个——访客等待更短。

## 二、把「主动性」拆成三层，只有一层交给模型

LLM 应用最容易翻车的地方是让模型自己决定"要不要主动说话"——闭源模型普遍过度热情（ProactiveBench 的结论）。
本项目的答案是把主动性拆开（`docs/ADR-0001`、`docs/ADR-0002`）：

1. **授权（能不能说）**：代码门控。访客可一键"别主动找我"；单会话硬上限 `TIP_QUOTA_MAX = 2`，弹满永久静默（`public/index.html`，commit `3dfee14`）。
2. **时机（什么时候说）**：构建期枚举。访客在哪个板块停留 ≥6s → 弹哪句预设话术，映射表写死在代码里。**模型不参与"是否开口"的判断**——模型判断不可复现，出问题查不到是数据还是脾气。
3. **措辞（怎么说）**：这才交给模型。

落地后用行为测试背书：jsdom 直驱真实页面 16/16 通过；**静置 126 秒零交互只弹 1 次**（N1 出口判据）。

## 三、单一事实源 + 构建期烘焙

- `public/resume.json` 是**唯一**事实源：页面渲染、AI 系统提示词、JD 生成器、甚至外部工具的接入配置，全部由它派生。
- Cloudflare Functions 没有文件系统 → `tools/gen-resume.mjs` 把简历和提示词**烘焙**成 `functions/api/_resume.mjs`。改简历不改代码，改完一条命令重烘焙。
- 派生物共 7 处（页面正文/侧栏/meta/兜底常量/两个提示词生成器/外站配置），换血时同批改、一处不漏（commit `9716f85` 的清单可查）。

**单一事实源的价值不在省事，在于一致性**：任何一处派生物撒谎，都会被另一次派生暴露。

## 四、把「诚实」做成工程约束，不靠模型自觉

提示词里写"不要编造"是没用的，要给结构：

- JD 匹配输出是**严格 JSON**，含 `gaps` 字段——JD 要求但简历缺失的点**必须如实列进去**，想回避都没有字段可藏（`functions/api/_jd.mjs` + `shared/prompt.mjs`）。
- 答不上来时的行为也是约束的一部分：明确指示转交本人（escalate），而不是硬答。
- 连"校名刻意不公开"都写了标准话术：被问到要说不便公开，而不是现编一个（commit `9716f85`）。
- 内容层的自我清理：删掉自评百分比（"95%"是最容易被认为是吹的呈现）、砍掉 4 个查无实证的技术标签、`education.school` 整字段撤下——**是删除，不是替换成更巧的说法**。

## 五、对外动作分层借力：开源管「手」，我们管「脑」

「自动投递」这一层不自研（`docs/ADR-0003`）：浏览器自动化、平台风控、登录态，全部交给成熟开源 `get_jobs`。
本项目的交付物只有一件事：把 `resume.json` **编译**成它的提示词模板（`tools/export-outbound.mjs`），并固化对方的三条接口契约（`String.format` 占位顺序、字面 `%` 转义、输出含 `false` 判失败）。

判据：**别人的发布节奏不要背在自己身上；但要接的那一小块接口，要挖到源码级**——契约是从对方 `Boss.java` 里实读出来的，不是抄 README。

## 六、安全默认 fail-closed，闸门不给人情

- 静态服务白名单 `PUBLIC_FILES`，未登记一律 404（deny by default）——黑名单漏一项就等于把密钥文件挂上网。
- `/api/*` 统一闸门 `_guard.mjs`：同源校验（拒 `null` 来源）+ 限流 + 消息长度/条数上限 + 角色白名单（防提示词注入）+ `max_tokens` 上限。
- 看板口令不匹配直接 401/403——**fail-closed**：宁可主人多输一次口令，不让访客联系方式裸奔。
- 限流的已知局限（单进程内存计数、挡不住代理池）写在 README 里——**知道自己防不住什么，也是安全设计的一部分**。

## 七、主动砍掉的东西（反模式清单）

判断力更多体现在不做什么：

- ❌ 随机定时弹窗（18–36s 循环骚扰）→ 换成板块感知 + 6s 停留 + 配额 2 次
- ❌ 技能自评百分比 → 纯文字列举，可信度靠项目证据撑
- ❌ Electron 经历、零实证技术标签 → 查无实据直接删
- ❌ 自研浏览器自动化投递 → 用开源，接口挖到源码级
- ❌ 让模型决定"何时开口" → 构建期枚举，可复现、可测试

## 八、阅读路线

1. `public/resume.json` —— 一切从这里派生
2. `shared/prompt.mjs` —— 人格与诚实约束的全部文本
3. `functions/api/_guard.mjs` —— 闸门（本地与 CF 共用同一份）
4. `docs/ADR-0001/0002/0003` —— 三个关键决策的完整推理
5. `public/index.html` 的 `adaptiveTip()` —— 主动性三层的落地处
